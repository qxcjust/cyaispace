本次更新

  • 新增：IDC 侧「WSHF 电源输出」测试项 —— 触发后输出持续保持 ON，直到下发关闭
  • 压测偏差提示改为单向：只标「低于目标 −N%」，N 可在页内改；压过头不再标红
  • NPU 压测的阈值独立落盘（不再与 CPU 共用一份配置）
  • 顶栏「设置 → 帮助 / 关于本系统」：检查更新 + 一键下载安装，有新版本时按钮点小红点
  • 安装程序欢迎页 / 完成页统一深蓝底，完成页文字不再隐形

安装说明

  • 双击 Setup 安装，路径不要带 #（Qt 找不到平台插件）
  • 安装时会请求一次管理员权限，用于放行入站 TCP 9100（Slave 服务）
  • 装完默认以工位机（Slave）角色启动；要只开界面，删掉 _internal\config\role.txt
已经装过的机器：打开程序 → 右上角 设置 → 关于本系统 → 检查更新， 程序会读本目录的 latest.json，有新版本时直接下载并启动安装程序。
